
# 🚀 Spring Boot Projects by Rahul Kumar

This repository contains backend projects built using **Spring Boot**, focusing on Java development, real-time messaging, resume generation, and secure REST APIs. These projects helped me learn backend development, authentication, WebSocket communication, and database integration using MySQL.

---

## 📁 Projects Included

### 1. 📝 Resume Builder  
📂 [`resumeBuilder`](https://github.com/Rahul230501/springbootProj/tree/main/resumeBuilder)

- Users enter personal, educational, and experience details  
- Resume is generated using **LaTeX templates**  
- Technologies: Spring Boot, Thymeleaf, MySQL, HTML/CSS, JavaScript  
- Features: Secure login,  clean UI  
- 📄 [Live README](https://github.com/Rahul230501/springbootProj/tree/main/resumeBuilder)

---

### 2. 💬 Chatroom App  
📂 [`chatroomapp`](https://github.com/Rahul230501/springbootProj/tree/main/chatroomapp)

- Technologies: Spring Boot, WebSocket, JavaScript

## 🛠️ Tech Stack Used

- **Backend**: Java, Spring Boot, Spring MVC, Spring Security  
- **Database**: MySQL, JDBC  
- **Frontend**: Thymeleaf, HTML5, CSS3, JavaScript  
- **Other Tools**: WebSocket, Git, Maven, LaTeX  

---

## 📦 How to Run Any Project

1. Clone the repo  
   ```bash
   git clone https://github.com/Rahul230501/springbootProj.git
   cd springbootProj
   ```

2. Choose the project folder (`resumeBuilder` or `chatroomapp`)  
3. Open in your IDE (IntelliJ / VS Code)  
4. Set up your MySQL DB and update `application.properties`  
5. Run using:
   ```bash
   mvn spring-boot:run
   ```

6. Visit `http://localhost:8080` to explore the app
